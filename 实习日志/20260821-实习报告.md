## AI 分析 + 导出 + 验收
1. 调 AI 生成文字分析（直接将llm_api.py照搬了过去）
2. 导出 Excel，分 sheet(根据stats_dict导出成6个sheet)
   - pd.ExcelWriter` 作用：实现单 Excel 文件内包含多个工作表 (sheet)。
在`with pd.ExcelWriter(路径) as writer:`代码块内，多次调用`to_excel`并指定不同`sheet_name`，多张表格写入同一个 Excel、互不覆盖。 
3. 导出 Markdown 报告
   1. 循环取出：表格标题`name`，表格 DataFrame`df`
   2. `df.to_markdown(index=False)` 
    > pandas 自带方法：**直接把 DataFrame 对象转换成 markdown 表格格式的字符串**，不用自己拼竖线。
    > `index=False`：不输出 pandas 的 0,1,2 行索引。

   3. `f.write()`把生成好的 markdown 表格字符串写入文件
4. F9：命令行参数化
    python main.py --input 数据.csv --output ./报告/ 
   >这使得能够读取不同的文件而不是固定的死文件，args = parser.parse_args()#读取你终端敲的一整行命令,把`‑i`后面的值拿出来，存到`args.input`,把`‑o`后面的值拿出来，存到`args.output`;`args.input` 拿到的就是你终端 `-i` 后面输入的**那一串字符串**，也就是你传入的文件路径。但是还需要进行后续的确定
