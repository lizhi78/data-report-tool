1. 解决中文乱码的过程：
   1. `现象`：matplotlib 默认用英文字体 Arial，中文显示成方框 □
   2. `尝试`：把 SimHei（黑体）字体文件拖进 C:\Windows\Fonts 安装
   3. `坑`：matplotlib 有字体缓存，装完新字体不会自动刷新，所以还是找不到 SimHei
   4. `诊断`：运行检测脚本发现，系统自带的微软雅黑（Microsoft YaHei）已经在 matplotlib 的缓存里了
   5. `最终解决`：代码最开头加两行，直接告诉 matplotlib 用微软雅黑
>plt.rcParams['font.sans-serif'] = ['Microsoft YaHei']
>plt.rcParams['axes.unicode_minus'] = False
1. argparse相关知识点：
    1. `parser=argparse.ArgumentParser(description=XXX)`创建一个参数解析对象，description四用来帮助说明的，当输入python xxx.py -h时，会显示这个描述
    2. `parser.add_argument()`常见的参数：
        | 参数 | 功能 |
        | :----: | :----: |
        | `--xxx` | 长参数名，终端使用：`--xxx 值`；可搭配短别名 `-x` |
        | `type` | 类型转换：`str`/`int`/`float`；仅转换文本，不会校验文件后缀、文件是否存在 |
        | `default` | 用户不传参数时，使用的默认值 |
        | `help` | 执行`-h`帮助时展示说明文字 |
        | `required=True` | 必填参数，不传入直接报错 |
        | `action="store_true"` | 开关参数，写上参数即为 True，不写 False；不要跟值 |
        | `choices=[...]` | 限定只能传入列表内的值 |
        | `nargs="+"` | 接收多个值，输出列表 |
2. `args=parser.parse_args()`:真正读取终端命令，生成 args，**全部参数定义完成后调用一次**
3. **注意** 缩写只有在终端(powershell)中使用，在代码里面只能使用全称，访问时要用args.全称
