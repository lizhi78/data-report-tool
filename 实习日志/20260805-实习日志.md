## python的上手入门2
- [x] 文件怎么读、怎么写
1. 文件的打开：with open ("path，'r/w/a',encoding="utf-8"") as f
2. 文件的读：1. f.read()读取全部内容，返回str
            2. f.readline()读取一行，返回str
            3. f.readlines()读取所有内容，返回list
3. 文件的写：1.w模式：会覆盖之前内容
            2.a模式：在之前内容之后续写
> w,a模式如果文件不存在，则直接创造文件
- [x] JSON 是什么、怎么读写
1. json.dumps()将python格式转化为json格式
2. json.loads()将json格式转化为python格式
- [x] 异常
try 可能出错的代码
except 如果出错的代码
else 如果正确执行的代码
finally 无论是否出错都执行的代码
