# 第三周总结
### 1.清洗和清洗报告
1. 删除完全空白数据和完全重复行
2. 处理缺失值(填充 fillna () / 删除 dropna ())
3. 日期清洗：先转字符串统一格式，再 to_datetime
   - 用正则匹配 "8月3日"、"2026/8/2" 等格式，统一成 "2026-8-3"。
   - pd.to_datetime(..., errors="coerce") 把无效日期变成 NaT；想区分"原本空"和"格式错误"，需用布尔标记做前后对比。
4.  清洗报告（F3）：用字典当账本，前后拍照对比
    - report = {} 记录每一步的"操作前数量 − 操作后数量"。
    - 关键技巧：执行前先 n = len(df)，执行后算 n - len(df)，得到精确删除/修改数。
### 2.异常值+统计
1. 异常数据处理
    - 异常判定：数量 > 1000、数量 ≤ 0、单价 ≤ 0，满足任一即标为 "异常"
    - 异常行三列全标 "异常"，正常行重新计算 销售额 = 数量 × 单价
    - 原销售额备份到 销售额_previous 列，保留原始数据备查
2. 统计分析
   - 用 pd.to_numeric(..., errors="coerce") 把 "异常" 转成 NaN，跳过空值做统计
   - groupby + sum + sort_values + reset_index 做分组汇总
日期用 pd.to_datetime 转换，再用 dt.strftime("%Y-%m") 提取年月分组
4. 数据清洗踩坑
   - 正则 r'(\d+)' 遇到小数会截断（1.99 → 1），单价要改用 r'(\d+\.?\d*)'
   - 先 str.replace 清理逗号/货币符号，再提取数字
   - .astype(object) 后数字变字符串，后续统计必须先 pd.to_numeric 转回来
### 命令行和excel，markdown导出
1. 命令行参数：用 argparse 接收 --input 和 --output，运行命令时直接告诉程序用哪个文件、存到哪里，不用打开代码改路径。
2. Excel 多 Sheet：用 pd.ExcelWriter 像"活页笔记本"一样，把多张表（清洗后数据 + 4个汇总）塞进同一个 Excel 文件的不同标签页。
3. Markdown 导出：把 DataFrame 转成 Markdown 表格文字，配合 f-string 拼接标题和内容，最后写进 .md 文件；也可以装 tabulate 用 df.to_markdown() 更省事
4. 调用 AI：把 stats_dict 里的汇总表拼成纯文字发给 DeepSeek，让 AI 写人话分析（有结论、有建议），从返回的 JSON 里取出 analysis 字段，写进 Markdown 最前面。
